# 🗺️ Choosing a Track

<table>
<tr>
<th align="left">Track</th>
<th align="left">Best for</th>
<th align="left">Trade-off</th>
</tr>
<tr><td>🎮 GamingPlus</td><td>Sustained load, low input latency</td><td>Higher power draw</td></tr>
<tr><td>👑 Legend</td><td>Flagship devices, full feature set</td><td>Heavier footprint</td></tr>
<tr><td>🥷 Ninja</td><td>Deep framework customization</td><td>More moving parts to maintain</td></tr>
<tr><td>⚡ Lite</td><td>Daily driving, older/mid devices</td><td>Fewer extras</td></tr>
<tr><td>🛡️ Vanguard</td><td>Set-it-and-forget-it stability</td><td>Minimal extra features</td></tr>
<tr><td>👻 Phantom</td><td>Privacy-first users</td><td>Some convenience services disabled</td></tr>
<tr><td>🌀 Overdrive</td><td>Kernel tuners, benchmarkers</td><td>Not a standalone daily ROM</td></tr>
</table>
